
# 🚑 Healthcare Analysis Dashboard (Power BI)

An end-to-end **Business Intelligence** project built with **Power BI** to analyze over **55,500 healthcare records** from **10 major U.S. hospitals (2019–2024)**. This dashboard transforms raw healthcare data into actionable insights, helping stakeholders monitor patient trends, hospital performance, financial metrics, and operational efficiency through interactive visualizations.

# 📌 Business Problem

Healthcare organizations generate vast amounts of patient and operational data every day. Without effective reporting, it becomes difficult to identify trends, optimize hospital performance, control healthcare costs, and improve patient outcomes.

This project addresses these challenges by transforming raw healthcare data into an interactive Power BI dashboard that enables data-driven decision-making for healthcare administrators and business stakeholders.

# 📊 Dashboard Overview

The dashboard provides comprehensive insights into:

- 👥 Patient admissions and discharge trends
- 🏥 Hospital performance comparison
- 💰 Revenue and billing analysis
- 🛡️ Insurance provider distribution
- 💊 Medication cost analysis
- 🩺 Disease prevalence and diagnosis trends
- ⏳ Length of hospital stay analysis
- 📈 Executive KPI monitoring

# 🔍 Key Insights

- 📈 Patient admissions increased by **7.5%** between **2019 and 2024**.
- 🏥 **Houston Methodist** treated over **20.4K patients**, generating approximately **$477M** in revenue.
- 💊 **Lipitor** was identified as the highest-cost medication.
- 🛡️ **Medicare** covered the largest patient population (**27.7K patients**).
- ⏳ Patients diagnosed with **Cancer** and **Diabetes** experienced the longest average hospital stays.
